# AI Development Control Plane Community

This repository is the public community gateway for the AI Development Control Plane program.

## What this repository is for

Use GitHub Discussions for ideas, questions, research, and early design conversation. Use the structured Work Proposal issue form when the requested outcome is concrete and actionable.

The implementation repositories are private. A community proposal may be evaluated and internally routed, but it does not grant access to private code or guarantee implementation.

## Architectural boundary

**CENTRALIZED AUTHORITY AND TRUTH; DISTRIBUTED CAPABILITIES AND OBSERVATIONS.**

Community input is development input only. It does not grant runtime Authority, Policy authority, canonical Registry truth, implementation acceptance, roadmap priority, release authority, merge authorization, or repository write access.

## Economic rule

The program is ZERO-SPEND + ECONOMIC-OPERATION by default. Proposals should prefer free/open-source, local/self-hosted, resource-efficient approaches and identify material compute, storage, network, token, or electricity implications when relevant.

## Before posting

- Search existing Discussions and Issues.
- Keep one primary problem or outcome per Work Proposal.
- Do not post secrets, credentials, private repository content, personal data, private host/network/device details, or vulnerability exploit details.
- Security vulnerabilities must use private vulnerability reporting.
- Read `CONTRIBUTING.md` and `SECURITY.md`.

## Proposal does not equal commitment

A proposal can be useful and still be deferred, redirected, duplicated, or not planned. `accepted-for-design` means design evaluation only; it does not prove implementation acceptance, priority, integration, release, or production authorization.
