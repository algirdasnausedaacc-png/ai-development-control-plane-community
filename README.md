# AI Development Control Plane Community

This repository is the proposed public community gateway for the AI Development Control Plane program.

## What this repository is for

Use GitHub Discussions for ideas, questions, research, and integration discussion. Use structured Issues for concrete work proposals, public bug reports, research evidence, and documentation improvements.

The current implementation repositories are private. A community proposal may be evaluated and internally routed, but it does not grant access to private code or guarantee implementation.

## Architectural boundary

**CENTRALIZED AUTHORITY AND TRUTH; DISTRIBUTED CAPABILITIES AND OBSERVATIONS.**

Community input is development input only. It does not grant runtime Authority, Policy authority, canonical Registry truth, acceptance, release authority, or repository write access.

## Economic rule

The program is ZERO-SPEND + ECONOMIC-OPERATION by default. Proposals should prefer free/open-source, local/self-hosted, resource-efficient approaches and identify material compute/storage/network/token/electricity implications.

## Before posting

- Search existing Discussions and Issues.
- One issue = one primary problem/outcome.
- Do not post secrets, credentials, private repository content, personal data, private network/host details, or vulnerability exploit details.
- Security vulnerabilities must use private vulnerability reporting.
- Read `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `GOVERNANCE.md`, `SECURITY.md`, and `SUPPORT.md`.

## Proposal does not equal commitment

A proposal can be useful and still be deferred, redirected, duplicated, or not planned. Public proposal status does not prove internal implementation acceptance or production authorization.
